# Skill Running With Video

## Overview

This repository is intended to host code and documentation for the **Skill Running With Video** project.
At the moment, the repository is in an early bootstrap stage and contains documentation only.

## Current Status

- Repository initialized
- Documentation baseline established
- No application source code yet
- No automated test framework configured yet

## Goals

The project is expected to evolve toward:

1. Implementing core "running with video" functionality
2. Providing reproducible development and testing workflows
3. Maintaining clear documentation for contributors

## Suggested Repository Structure

As implementation starts, a structure like this is recommended:

```text
.
├── README.md
├── src/                # application source code
├── tests/              # automated tests
├── scripts/            # helper scripts (build/test/dev)
└── docs/               # additional documentation
```

## Getting Started

Since there is no runnable code yet, setup is currently minimal:

1. Clone this repository
2. Create your feature branch
3. Add source code and tests in dedicated directories
4. Keep documentation updated with each change

## Testing

There is currently **no test script configured** in this repository.

When implementation begins, add a standard test command and document it here, for example:

- `npm test` (Node.js)
- `pytest` (Python)
- `go test ./...` (Go)

## Contribution Guidelines

- Keep changes focused and atomic
- Add or update tests together with feature changes
- Update `README.md` when behavior or setup changes
- Use descriptive commit messages

## Changelog Policy

Track meaningful updates in commit history and optionally maintain a dedicated `CHANGELOG.md` once the project grows.
